Robot Rescue

Rescate del Robot

Learn how an algorithm is a sequence of steps. Think first, plan the route, run it and debug it if something goes wrong.

Aprende que un algoritmo es una secuencia de pasos. Piensa primero, planea la ruta, ejecútala y corrígela si algo sale mal.

🧠 Build the ideaConstruye la idea

THINK → PLAN → RUN → CHECK → DEBUG → TRY AGAIN
1️⃣2️⃣3️⃣

Sequence

Steps must be in the correct order.

Los pasos deben estar en el orden correcto.

🤖

Algorithm

An algorithm is a set of instructions to reach a goal.

Un algoritmo es un conjunto de instrucciones para alcanzar una meta.

🛠️

Debug

If the plan fails, find the first wrong step and improve it.

Si el plan falla, encuentra el primer paso incorrecto y mejóralo.
