11TH BLUE · CYCLE 4 · 60 MINUTES

Engineering Project Review & Sprint 1

Class objective: identify the real current stage of the team project and complete the next engineering milestone for a robotic system that integrates sensors, actuators, ESP32/WiFi and a web monitoring/control interface.

🌟 Open 11th Blue ProjectsOpen Cycle 4 Guide

1. Find your real stage

IDEA→ARCHITECTURE→PROTOTYPE→SIMULATION→INTEGRATION→TESTING→DOCUMENTATION

Do not say “finished” because you created folders or a nice interface. Evidence determines the stage.

2. One-hour class plan

0–5Open your team page.
5–12Read what is already completed.
12–22Define one final problem and solution.
22–35Draw system architecture.
35–45Design input/process/output + dashboard.
45–55Write 3 tests and next tasks.
55–6060-second team pitch.

3. Architecture you must be able to explain

REAL PROBLEM ↓ SENSOR / INPUT ↓ ESP32 ↓ PROCESS / CONDITION ↓ ACTUATOR / OUTPUT ↓ WiFi / DATA ↓ WEB DASHBOARD ↓ USER DECISION / MONITORING

4. Minimum technical decisions

  • Problem and target user
  • ESP32
  • At least one justified sensor
  • At least one justified actuator
  • Decision rule: IF condition → action
  • What data will travel over WiFi
  • What the web dashboard must show
  • ODS relationship

📱 No computer lab? The sprint still works.

With one phone per group, use the public project page only as reference. The actual deliverable can be written in a notebook or shared Google Doc. Do not waste the hour trying to code an entire Wokwi simulation from the phone.

✅ Deliverable at the end of the hour: Project Sprint Card v1

PROJECT NAME: TEAM: 1. REAL PROBLEM: 2. TARGET USER: 3. FINAL SOLUTION: 4. SENSOR(S): 5. ACTUATOR(S): 6. ESP32 DECISION RULE: 7. DATA SENT BY WiFi: 8. WEB DASHBOARD MUST SHOW: 9. ODS: 10. THREE TESTS: T1: T2: T3: 11. NEXT THREE TASKS: A: B: C:

Teacher checkpoint

  • ☐ The team selected ONE concrete problem.
  • ☐ The sensor and actuator have a reason to exist.
  • ☐ They can explain Input → Process → Output.
  • ☐ They drew the dashboard before coding it.
  • ☐ They wrote at least three test cases.
  • ☐ Their claimed progress matches actual evidence.
