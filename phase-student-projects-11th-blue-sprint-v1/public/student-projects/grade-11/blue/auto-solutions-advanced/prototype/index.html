// Archivo: wokwi/riego_inteligente/sketch.ino
#include <WiFi.h>
#include <ESP32Servo.h>

const char* ssid = "Wokwi-GUEST";
const char* password = "";

const int POT_PIN = 34; // Sensor de Humedad Analog
const int SERVO_PIN = 18; // ServomotorSG90
Servo servoVálvula;

void setup() {
  Serial.begin(115200);
  servoVálvula.attach(SERVO_PIN);
  WiFi.begin(ssid, password);
  Serial.println("Conectando a WiFi Wokwi...");
}

void loop() {
  int sensorVal = analogRead(POT_PIN);
  float humedadPct = (sensorVal / 4095.0) * 100.0;
  
  if (humedadPct < 40.0) {
    servoVálvula.write(180); // Abrir Válvula
  } else {
    servoVálvula.write(0); // Cerrar Válvula
  }
  delay(1000);
}

Resumen

El presente proyecto aborda el diseño, simulación e implementación de un sistema robótico inteligente basado en el microcontrolador ESP32 integrado con una interfaz web en tiempo real desarrollada en HTML5, CSS3, JavaScript y Chart.js. Mediante la metodología de Aprendizaje Basado en Proyectos (ABP) y el enfoque STEM, se desarrolló una solución automatizada para el monitoreo ambiental y gestión eficiente de recursos en la comunidad escolar, alineada con los Objetivos de Desarrollo Sostenible (ODS 6, 9, 11 y 13). Los resultados evidencian la viabilidad de la telemetría inalámbrica simulada a través de Wokwi, incluyendo telemetría simulada y mecanismos de control que aún deben ser validados mediante pruebas documentadas.

1. Introducción

La automatización de procesos mediante la Robótica e Internet de las Cosas (IoT) representa uno de los pilares fundamentales de la Cuarta Revolución Industrial. Sin embargo, su verdadero valor radica en la capacidad de resolver problemas reales comunitarios bajo una perspectiva ética y ambientalmente sostenible. La pregunta orientadora planteada fue: ¿Cómo podemos integrar un sistema robótico con una interfaz web para crear una solución automatizada que aborde un problema real de nuestra comunidad, considerando las implicaciones éticas y alineándonos con los ODS?

2. Metodología

Se siguió el Proceso de Diseño en Ingeniería en 9 etapas. El hardware simulado en Wokwi incluyó un microcontrolador ESP32, sensores DHT22 (temperatura/humedad), potenciómetros analógicos (simulación de humedad del suelo) y actuadores como servomotores SG90 y LEDs. La interfaz web utiliza un diseño glassmorphism responsivo con almacenamiento persistente en localStorage y calculadoras estadísticas STEM integradas.
