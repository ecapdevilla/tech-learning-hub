## START-OF-SESSION RULE
When a new AI session begins, the user should say:

"Read AI_HANDOFF.txt first. Use it as the current project state.
Do not scan the whole repository.
Check only git status, git log -5 --oneline, and the files related to the task I give you."

The AI must:
1. Read AI_HANDOFF.txt.
2. Run/check git status.
3. Run/check git log -5 --oneline.
4. Work only on files related to the requested task.
5. Avoid broad repository scans unless absolutely necessary.

## END-OF-SESSION RULE
Before finishing a meaningful work session, the AI must update this file with:
- Current HEAD commit.
- What was changed.
- Files / modules affected.
- Database changes or migrations.
- What was tested.
- What remains pending.
- Any warnings / decisions the next AI must know.

Then the AI should commit the handoff update with the related work or immediately after it.
