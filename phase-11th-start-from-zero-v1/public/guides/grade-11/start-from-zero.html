🎯 Class objective

Design the first complete blueprint for a technological solution that addresses a real problem and can later become a functional system integrating ESP32, sensor(s), actuator(s), WiFi, Wokwi and a web dashboard.

Your complete route

1 · PROBLEM + ODS→ 2 · SOLUTION→ 3 · ARCHITECTURE→ 4 · WOKWI MVP→ 5 · WEB DASHBOARD→ 6 · INTEGRATION→ 7 · TESTING→ 8 · DOCUMENTATION

Today you do not need to finish the whole project. You need to leave Steps 1–3 strong enough that implementation can begin immediately.

1 · Choose a real problem

  • What happens?
  • Who is affected?
  • Why is it worth solving?
  • Which SDG (ODS) is related?
  • What could technology measure, detect or automate?

2 · Define your solution

Do not start by choosing random sensors. First explain what the system must accomplish.

Our system will: DETECT / MEASURE __________ PROCESS ___________________ DECIDE ____________________ ACT ON ____________________ SHOW ON THE WEB ___________

3 · Build the engineering architecture

REAL PROBLEM + ODS ↓ SENSOR / INPUT ↓ ESP32 ↓ PROCESS / IF CONDITION ↓ ACTUATOR / OUTPUT ↓ WiFi / DATA ↓ WEB DASHBOARD ↓ USER / DECISION

4 · Minimum MVP

  • One ESP32.
  • At least one justified sensor.
  • At least one justified actuator.
  • One automatic IF/THEN rule.
  • One Wokwi simulation.
  • One web dashboard with useful data/status.
  • At least three documented tests.

5 · Dashboard blueprint

┌────────────────────────────┐ │ PROJECT NAME STATUS │ ├────────────────────────────┤ │ SENSOR VALUE: ________ │ │ SYSTEM STATE: ________ │ │ │ │ [ chart / history ] │ │ │ │ [ CONTROL ] [ RESET ] │ ├────────────────────────────┤ │ ALERTS / EVENTS │ └────────────────────────────┘

This is only a wireframe. Do not copy this visual design as your final interface.

📱 Only a phone available?

You can complete the entire planning milestone from a phone + notebook. Research only the components your solution actually needs. Do not spend the hour copying definitions or trying to build the entire Wokwi project on a small screen.

⚡ Accelerator: what comes immediately after this?

  1. Create the first Wokwi circuit with only the minimum components.
  2. Make the sensor produce a value.
  3. Program the IF/THEN automation rule.
  4. Make the actuator respond correctly.
  5. Create the web interface from your own design.
  6. Simulate or implement the data flow.
  7. Test normal, limit and failure conditions.
  8. Document screenshots, results, limitations and improvements.
