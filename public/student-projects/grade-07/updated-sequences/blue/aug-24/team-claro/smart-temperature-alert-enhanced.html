Nombre del Sistema: Smart Temperature Alert System

Problema / Propósito: Alertar automáticamente cuando la temperatura supera un umbral seguro (30°C). Útil para monitorear servidores, invernaderos o aulas.

¿Quién se beneficia? Administradores, profesores, personal de TI y cualquier persona que necesite monitoreo de temperatura.

Entradas (Inputs):

  • Valor de temperatura (°C) — Lectura simulada de sensor digital

Lógica (Process):

  • IF temperatura > 30 °C THEN activar alerta
  • ELSE mantener estado normal

Salidas (Outputs):

  • Alerta Visual: Cambia de "Normal" a "Alerta" con cambio de color
  • LED Indicador: Se enciende (rojo) durante la alerta
  • Buzzer: Se activa (simulado) durante la alerta
  • Ventilador: Se activa para enfriar (simulado)

Diagrama del Sistema:

        👁️ SENSE              🧠 THINK              ⚙️ ACT
        ┌────────────┐       ┌────────────┐       ┌────────────┐
        │ Temperatura │ ──→  │  IF > 30   │ ──→  │  Alerta    │
        │   (Input)   │       │   THEN     │       │  LED       │
        │   22.0 °C   │       │   ELSE     │       │  Buzzer    │
        └────────────┘       └────────────┘       │  Ventilador│
                                                    └────────────┘

Bug Encontrado & Solución: La versión inicial no manejaba correctamente el valor límite 30.0. Se solucionó usando > en lugar de >= para que 30.0°C sea considerado normal.
