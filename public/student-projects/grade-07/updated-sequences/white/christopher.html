📐 Especificación técnica

Blueprint
Proyecto WasteSort · Clasificador Automático
Problema Residuos mal clasificados en el hogar
Sensor Selección manual (simula sensor óptico)
Detecta Tipo de material (plástico, orgánico, peligroso, textil)
Regla de decisión
IF material ∈ {plástico, cartón, vidrio, lata} THEN ♻️ Reciclable → contenedor AZUL
ELSE IF material = "Restos de Comida" THEN 🌱 Orgánico → contenedor VERDE
ELSE IF material ∈ {Pilas, Medicamentos, Aceite usado} THEN ⚠️ Peligroso → contenedor ESPECIAL
ELSE 🧵 No reciclable → donación / contenedor TEXTIL
Actuador Brazo robótico + indicador visual
Estado normal 🟢 En espera
Estado alerta 🔴 Peligroso → protocolo especial
Simulador: Wokwi · Tinkercad IF / THEN / ELSE Sensor + Actuador

🔄 Iteración & reflexión

Post‑simulación
📌 Mejora tras revisión de pares:
Se amplió la clasificación de residuos para incluir materiales no reciclables como ropa/textiles y aceite usado. Ahora el sistema distingue entre 4 categorías: reciclable, orgánico, peligroso y no reciclable. Cada una tiene un contenedor específico y una acción clara (reciclar, compostar, desechar seguro, donar).
💭 Reflexión:
La simulación permitió validar la lógica de clasificación con 9 materiales diferentes, incluyendo aquellos que no son reciclables. Esto mejoró la precisión del sistema y enseñó que no todos los residuos van al mismo lugar. El feedback visual (color, íconos, mensajes) ayuda a que el sistema sea comprensible para cualquier usuario, cumpliendo el objetivo de “simular antes de construir”.
