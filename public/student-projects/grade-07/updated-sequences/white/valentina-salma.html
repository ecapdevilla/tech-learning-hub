📋 Blueprint del Sistema

PROJECT NAME: Sistema Automatizado de Clasificación de Residuos

PROBLEMA: En una planta de reciclaje, los residuos deben clasificarse en tres categorías: reciclable (plástico/vidrio), orgánico y peligroso (metales/electrónicos). El proceso manual es lento y propenso a errores.

INPUT / SENSOR: Sensor de proximidad ultrasónico (simulado) que detecta el tipo de residuo según la distancia.

QUÉ DETECTA: Distancia en cm (simulada). 0-10cm = reciclable | 11-20cm = orgánico | 21-30cm = peligroso

DECISION RULE:
IF distancia <= 10 THEN residuo reciclable → LED verde
ELSE IF distancia <= 20 THEN residuo orgánico → LED amarillo
ELSE IF distancia <= 30 THEN residuo peligroso → LED rojo + ALERTA

OUTPUT / ACTUATOR: LEDs indicadores (verde, amarillo, rojo) y sistema de alerta

NORMAL STATE: LED verde (residuo reciclable)

ALERT / ACTION STATE: LED rojo + mensaje de alerta (residuo peligroso)

🔨 Mejora después de revisión por pares

Feedback recibido: "Sería útil que el sistema mostrara el tipo de residuo con un ícono más claro, que la alerta de peligroso sea más visible y que tenga actividades interactivas para aprender jugando."

Mejora implementada:

  • Se agregaron íconos visuales (♻️ 🌿 ⚠️) para cada tipo de residuo.
  • La alerta de residuo peligroso ahora parpadea y tiene un mensaje destacado en rojo.
  • Se añadió un indicador de estado (NORMAL / ALERTA) para mayor claridad.
  • Los LEDs ahora tienen animaciones de brillo más realistas.
  • 🎮 3 juegos educativos: Clasificación Rápida, Verdadero o Falso y Memoria de Residuos.
  • 🎯 Modos de dificultad: Principiante (fácil) y Experto (difícil).
  • 📊 Sistema de calificación con nota final y mensaje personalizado.
  • El diseño es completamente responsive para móviles.
  • 🎨 Colores neón y vibrantes en todo el sistema.

💡 Reflexión: ¿Cómo ayudó la simulación a mejorar el diseño?

La simulación nos permitió probar diferentes escenarios de clasificación sin necesidad de componentes físicos. Pudimos verificar que la lógica IF / ELSE IF funcionaba correctamente para cada rango de distancia.

También nos ayudó a identificar que la alerta de residuo peligroso necesitaba ser más notoria, por lo que agregamos un mensaje parpadeante y un LED rojo más brillante en la simulación. Esto nos ahorró tiempo y recursos antes de pasar a la construcción física.

📌 Lección aprendida: Simular antes de construir permite detectar errores de lógica y mejorar la experiencia del usuario de forma rápida y económica.
