💻 Código Arduino Wokwi

// SMART KITCHEN ASSISTANT
const int LM35 = A0;
const int LED_VERDE = 2;
const int LED_ROJO = 3;
const int BUZZER = 4;

float temp = 0;
int tiempo = 0;
bool alarma = false;

void loop() {
  temp = analogRead(LM35) * 5.0 / 1023.0 * 100.0;

  if (temp > 60) {
    tiempo++;
    if (tiempo > 20 && !alarma) {
      alarma = true;
      Serial.println("🚨 ALERTA!");
    }
  } else {
    tiempo = 0;
    alarma = false;
  }

  if (alarma) {
    digitalWrite(LED_VERDE, LOW);
    digitalWrite(LED_ROJO, HIGH);
    tone(BUZZER, 1000, 200);
  } else {
    digitalWrite(LED_VERDE, HIGH);
    digitalWrite(LED_ROJO, LOW);
    noTone(BUZZER);
  }
  delay(1000);
}

📝 Mejora & Reflexión

🔧 Mejora implementada:

Se agregó un temporizador de 20 segundos antes de activar la alarma para evitar falsas alertas por cambios breves de temperatura. También se añadió un LED verde para indicar estado seguro.

💭 Reflexión:

La simulación permitió probar el sistema sin necesidad de componentes físicos. Pude ajustar el umbral de temperatura y el tiempo de activación de la alarma, verificando que los LEDs y el buzzer respondieran correctamente antes de construir el circuito real. Esto ahorra tiempo, evita dañar componentes y permite iterar rápidamente en el diseño.
