❓ Pregunta Orientadora:

"¿Cómo podemos integrar un sistema robótico con una interfaz web para crear una solución automatizada que aborde un problema real de nuestra comunidad, considerando las implicaciones éticas y ambientales, y alineándonos con los Objetivos de Desarrollo Sostenible (ODS)?"

🛠️ Arquitectura del Sistema (Robot ESP32 ↔ Web)

Diapositiva 3 / 6
📡

1. Hardware & Wokwi

Microcontrolador ESP32 DevKit v1, Sensores analógicos/digitales (DHT22, PIR, HC-SR04, Potenciómetro) y actuadores (Servo SG90, LED, Buzzer).

🌐

2. Comunicación WiFi

Conexión WiFi simulada enviando tramas de datos JSON cada 2000 ms a la interfaz web con latencia inferior a 200 ms.

📊

3. Dashboard Web SPA

Interfaz responsiva HTML5/CSS Glassmorphic, gráficos en tiempo real con Chart.js y almacenamiento local localStorage.

⚡ Control Bidireccional Remoto:

El usuario puede visualizar las variables físicas en vivo y pulsar interruptores en la pantalla web para accionar válvulas o alarmas en el robot de forma remota.

🧮 Integración STEM: Matemáticas y Ciencias Naturales

Diapositiva 5 / 6

➕ Aplicación de Matemáticas:

  • Conversión ADC 12-Bits: $V_{out} = \frac{\text{RAW}}{4095} \times 3.3\,\text{V}$
  • Estadística Descriptiva: Cálculo en tiempo real de la media ($\mu$) y desviación estándar ($\sigma$) de las lecturas.
  • Geometría PWM: Conversión de distancias a ancho de pulso microsegundos ($500\,\mu s - 2500\,\mu s$) para el Servomotor SG90.

🔬 Aplicación de Ciencias Naturales:

  • Evapotranspiración ($ET_0$): Modelo agroclimático Hargreaves para calcular la demanda hídrica en Litros por $m^2$.
  • Calidad del Aire & Confort: Cálculo de la sensación térmica (*Heat Index*) y niveles aceptables de $CO_2$ en PPM.
  • Ciclo del Agua y Energía: Reducción directa del desperdicio de agua y ahorro de energía eléctrica.
