🧩 ¿Qué problema solucionamos?

Muchos estudiantes tienen dificultades para organizar sus actividades escolares, recordar fechas de entrega y diferenciar las tareas académicas de aquellas relacionadas con acciones ambientales.


EcoStudy centraliza estas actividades en una aplicación sencilla y permite realizar seguimiento del progreso.

🏗️ Arquitectura MVC

  • Modelo: Usuario, Tarea y Categoría.
  • Vista: HTML + CSS y renderizado dinámico.
  • Controlador: eventos, filtros, creación y actualización.
  • Persistencia: localStorage.

🤖 Ingeniería de prompts

La IA puede utilizarse como copiloto durante el proyecto. Ejemplo de prompt:


"Escribe una función JavaScript que filtre tareas por categoría y estado, usando arquitectura MVC, validando los datos y explicando cada paso."
