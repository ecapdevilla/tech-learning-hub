🎯 Nuestra problemática

En la escuela, los estudiantes pueden tener dificultades para organizar sus tareas, recordar fechas de entrega y mantener un seguimiento de sus actividades. Además, utilizar hojas de papel para anotar constantemente las tareas puede generar un consumo innecesario de recursos.

💡 Nuestra solución

EcoStudy centraliza las tareas en una herramienta digital, permitiendo organizarlas por categorías, marcar su estado y consultar el progreso.

🌍 Objetivos de Desarrollo Sostenible

EcoStudy y los ODS

La aplicación relaciona una necesidad educativa con una acción tecnológica que también promueve un consumo más responsable.

ODS 4

Educación de calidad

EcoStudy facilita la organización del aprendizaje, ayuda a realizar seguimiento de las tareas y permite que los estudiantes tengan una herramienta digital para gestionar sus responsabilidades académicas.

ODS 12

Producción y consumo responsables

Al digitalizar la organización de tareas se puede disminuir el uso innecesario de hojas, cuadernos y otros materiales utilizados únicamente para recordar actividades.

♻️ Impacto esperado

Educativo: mejor organización, seguimiento y responsabilidad del estudiante.

Ambiental: menor dependencia del papel para registrar y consultar tareas.

Tecnológico: aplicación práctica de HTML, CSS, JavaScript, MVC y almacenamiento local.

Social: fomenta hábitos de organización y responsabilidad dentro de la comunidad escolar.

💭 Reflexión

Una pequeña solución tecnológica puede generar cambios en los hábitos cotidianos. EcoStudy demuestra que la programación no solamente sirve para crear aplicaciones, sino también para responder a problemas reales de nuestra comunidad. Al organizar las tareas digitalmente, buscamos mejorar el proceso educativo mientras promovemos decisiones más responsables sobre los recursos que utilizamos.

🧩 Arquitectura del proyecto

Arquitectura MVC

EcoStudy está construido utilizando el patrón Modelo-Vista-Controlador, separando los datos, la interfaz y la lógica de funcionamiento.

🗃️

MODELO

Administra los datos de la aplicación.

  • Usuario
  • Tarea
  • Categoría
  • localStorage
  • Estado de las tareas
🖥️

VISTA

Es la interfaz con la que interactúa el usuario.

  • HTML
  • CSS
  • DOM
  • Formularios
  • Tarjetas y estadísticas
⚙️

CONTROLADOR

Conecta el modelo con la vista.

  • Eventos
  • Agregar tareas
  • Eliminar tareas
  • Completar tareas
  • Filtrar información

IA como aliada

La inteligencia artificial puede ayudar a generar, explicar, depurar y mejorar código. Sin embargo, el equipo debe revisar, comprender y probar las respuestas obtenidas.

🚀 Prompt 3 · Mejora del proyecto

PROMPT
Refactoriza este código MVC para hacerlo más modular, legible y fácil de probar. No utilices frameworks. Mantén las entidades Usuario, Tarea y Categoría. Agrega comentarios JSDoc y manejo de errores.

⚠️ Uso responsable de IA

La IA no reemplaza al equipo de desarrollo. La utilizamos como copiloto para obtener ideas, detectar errores y aprender conceptos. Antes de incorporar código generado por IA, debemos leerlo, comprenderlo, probarlo y adaptarlo a las necesidades del proyecto.
