🚦 ¿Qué hacer en un semáforo amarillo?
Situación: Llegas a un semáforo que cambia a amarillo. ¿Cuál es la acción correcta?
🚦
📸 Escenario: Semáforo amarillo intermitente en intersección urbana.
(Simulación de tránsito · Conducción segura)
// Simulación de decisión
función evaluarSemáforo(velocidad, distancia) {
  if (distancia < 10 && velocidad > 40) {
    return "¡Frena con seguridad!";
  } else {
    return "Continúa con precaución";
  }
}
