🎯 Objetivo del proyecto

Diseñar, programar y presentar un proyecto interactivo funcional (juego de preguntas) usando Scratch que resuelva un problema real: falta de conciencia sobre reciclaje y ahorro de agua en la escuela.

¿Cómo podemos usar variables, condicionales, ciclos y listas para crear un juego interactivo que enseñe a separar residuos y cuidar el agua?

📌 Proyecto: EcoQuiz · Reciclaje y agua

🎯 Propósito: Educar mediante preguntas sobre separación de residuos, ahorro de agua y energía.

📦 Variables: score lives name

🔀 Condición: si score ≥ 8 → ganar

🔁 Ciclo: repetir 6 preguntas

📚 Lista (desafío): preguntas, respuestas, pistas

🧠 Bloques · estructura
// variables score = 0 lives = 3 name = "" // entrada ask "¿Cómo te llamas?" → name // condicional if score >= 8 { say "¡Ganaste! 🌟" } // ciclo + lista questions = ["¿Plástico se recicla?", "¿Ahorrar agua?"] answers = ["sí", "cerrar grifo"] repeat 6 times { ask questions[i] if answer == answers[i] { score += 1 } else { lives -= 1 } }
