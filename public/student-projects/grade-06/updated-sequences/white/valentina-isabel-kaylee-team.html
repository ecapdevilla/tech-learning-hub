Educación + Tecnología

En nuestra escuela, muchos residuos terminan en el contenedor equivocado. ReciclaLab es un juego interactivo que enseña a clasificar plástico, papel, vidrio y orgánico, ¡convirtiendo el aprendizaje en una aventura!

🧩 Programación en Scratch 🌱 STEM + ODS ♻️ Reciclaje

🧠 Clase Maestra · Los 5 Bloques Scratch

📦 Variable
score = 0
lives = 3
player = "Ana"
⌨️ Entrada
ask "¿Cómo te llamas?"
answer → player
🔀 Condicional
IF answer = "plástico" THEN
  change score by 1
🔁 Ciclo
REPEAT 5 TIMES
  ask "¿Dónde va el vidrio?"
📚 Lista ⭐
preguntas = ["plástico?", "papel?", "vidrio?"]
respuestas = ["amarillo", "azul", "verde"]
✅ Integración
// Todas las estructuras trabajan juntas
REPEAT len(preguntas)
  IF respuesta = correcta THEN
    change score by 1
✅ Preguntas rápidas:
1. Puntuación → Variable  |  2. Decisión → Condicional  |  3. Repetir → Ciclo  |  4. Muchas preguntas → Lista

Step B · Entrada
ask "¿Cómo te llamas?" and wait
say (join "Bienvenido/a " (answer))
Bienvenido/a Valentina
Step C · Decisión
if (answer = "plástico") then
  change score by 1   say "¡Correcto!"
else say "¡Intenta de nuevo!"
✅ ¡Correcto! +1 punto
Step D · Ciclo
repeat 5
  ask "¿Dónde va el vidrio?" and wait
  check answer
