SENSOR → CONDITION → DECISION → ACTION → LOOP
👁️

Sensor

Detects something in the environment.

Detecta algo en el entorno.

❓

Condition

Checks if something is true or false.

Comprueba si algo es verdadero o falso.

⚡

Action

What the robot does after deciding.

Lo que hace el robot después de decidir.

🔁

Loop

Repeats instructions efficiently.

Repite instrucciones de forma eficiente.

🔎 Think before codingPiensa antes de programar

Challenge A
IF sensor detects trash THEN collect trash

What is the sensor information? What is the action?

¿Cuál es la información del sensor? ¿Cuál es la acción?

Challenge B
REPEAT 3 TIMES MOVE FORWARD

How many moves happen? Why is the loop useful?

¿Cuántos movimientos ocurren? ¿Por qué es útil el ciclo?
