Conceptos clave

Objetivo de aprendizaje: Comprender qué es un dashboard, cómo se usa una tabla dinámica y cómo una gráfica comunica información útil.
1. Datos brutos

Son cifras o información sin organizar. A veces no dicen mucho si se miran solos.

2. Tabla dinámica

Permite resumir, agrupar y reorganizar la información para encontrar patrones.

3. Gráfica dinámica

Se actualiza cuando cambian los filtros o los datos, y ayuda a visualizar tendencias.

4. Dashboard

Es un conjunto de tablas, gráficas y filtros que ayudan a tomar decisiones.

Pregunta clave: “¿Qué pregunta estoy intentando responder con estos datos?”
35–60 min

Práctica guiada

Misión: Usa la tabla dinámica que trabajaste en el ciclo anterior y conviértela en un dashboard simplificado.
  1. Abre la hoja de cálculo con tus datos.
  2. Selecciona la tabla dinámica y revisa la información.
  3. Inserta una gráfica de barras para comparar categorías.
  4. Inserta una gráfica de líneas para observar tendencias.
  5. Agrega un filtro o slicer para analizar cada categoría.
  6. Aplica formato condicional para resaltar resultados importantes.
  7. Escribe un título claro y etiquetas que ayuden a entender la gráfica.
En tu cuaderno: ¿Qué cambia cuando aplicas un filtro? Escribe tu predicción antes de probarlo.
