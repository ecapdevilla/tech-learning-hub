15–35 min

Development / Representation

Objective: Students will build a dynamic dashboard using pivot tables, charts, slicers and conditional formatting to interpret meaningful patterns and communicate a clear data story.
1. Dynamic chart vs static chart

A static chart shows one fixed view. A dynamic chart updates with filters, slicers or connected data.

2. Pivot table

Lets students group, summarize and reorganize data efficiently.

3. Chart selection

Bar charts compare categories. Line charts show trends over time.

4. Dashboard design

Combines tables, charts, conditions and filters to help decision-making.

Professional question: “What question am I trying to answer with this data?”
35–60 min

Guided Practice

Mission: Use the pivot table created in Cycle 3 and transform it into a dashboard.
  1. Select the pivot table from the previous cycle.
  2. Insert a bar chart to compare categories.
  3. Insert a line chart to observe trends over time.
  4. Add a slicer or filter to analyze each category.
  5. Apply conditional formatting to highlight key results.
  6. Write a title and labels that communicate the story clearly.
Show a slicer or filter and ask: What should change when a slicer or filter is applied?
