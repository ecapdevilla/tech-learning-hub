Step 1Paso 1: Identificar el Problema

  • Conocer los ODS: Educación de Calidad, Innovación y Comunidades Sostenibles.
  • Identificar un desafío escolar o comunitario que pueda resolver la tecnología.
  • Formular la pregunta: ¿Cómo usar variables, condicionales, ciclos y funciones para resolverlo?
  • Learn the SDGs: Quality Education, Innovation, and Sustainable Communities.
  • Identify a school or community challenge that technology can solve.
  • Ask: How can we use variables, conditionals, loops, and functions to solve it?
4

Step 2Paso 2: Formar los Equipos

Roles sugeridos: Desarrollador Principal, Diseñador UI/UX, Gestor de Datos, Líder de Documentación y Presentador.

Suggested roles: Lead Developer, UI/UX Designer, Data Manager, Documentation Lead, and Presenter.

Step 3Paso 3: Investigar y Planificar

  • Investigar variables, condicionales, ciclos, funciones, arrays y eventos.
  • Crear bocetos, wireframes y un diagrama de flujo.
  • Elegir el tipo de proyecto: juego, herramienta educativa o gestor de datos.
  • Research variables, conditionals, loops, functions, arrays, and events.
  • Create sketches, wireframes, and a flowchart.
  • Choose the project type: game, educational tool, or data manager.

Step 4Paso 4: Diseñar el Prototipo

Design the interface and logic: HTML/CSS for layout, JavaScript for behavior and data.

Step 5Paso 5: Construir y Programar

  • Agregar validación, contenido dinámico y feedback interactivo.
  • Set up VS Code and create HTML, CSS, and JavaScript files.
  • Use variables, conditionals, loops, functions, arrays, and events.

Step 6Paso 6: Probar y Recolectar Datos

Probar con usuarios, corregir bugs, medir tiempos y registrar retroalimentación.

Test with users, fix bugs, measure performance, and collect feedback.

Step 7Paso 7: Mejorar el Diseño
