🧠 2. Planning Before Coding

Engineering habit: Good programmers do not start by typing. They first understand the problem, define variables and decide how the user will interact.

🧩 3. Programming Structures

📦
Variable

Stores information that can change.

🔀
Conditional

Checks a decision: IF true → action.

🔁
Loop

Repeats instructions efficiently.

📚
List / Array

Stores several related values.

🛠️ 4. Build Logic

STEP 1 · Variable + interaction

when green flag clicked set [score] to [0] ask [What is your name?] and wait say (join [Hello ] (answer)) for [2] seconds

STEP 2 · Condition + loop

repeat [3] ask [2 + 2 = ?] and wait if <(answer) = [4]> then change [score] by [1] say [Correct!] else say [Try again!] end end

STEP 3 · Advanced list challenge

create list [questions] add [2 + 2] to [questions] add [5 + 3] to [questions] use an index to visit each item
Professional rule: Adapt the logic to your project. Do not copy without understanding.
