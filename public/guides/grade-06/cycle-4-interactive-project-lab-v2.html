🧠 2. Clase maestra · Los cinco bloques

15–40 min
📦

Variable

Un espacio con nombre que guarda información.

score = 0 lives = 3 name = "Ana"
⌨️

Entrada del usuario

La información que el usuario escribe.

ask "¿Cómo te llamas?" answer → name
🔀

Condicional

Si ocurre algo, se ejecuta una acción.

IF score >= 10 YOU WIN
🔁

Ciclo

Repite instrucciones de forma eficiente.

REPEAT 5 TIMES ask question
📚

Arreglo / Lista ⭐ desafío avanzado

Es una estructura que guarda varios valores relacionados.

questions = ["2+2?", "5+3?", "10-4?"] answers = ["4", "8", "6"]
Pregunta rápida 1: ¿Qué estructura debe guardar la puntuación del jugador?
Pregunta rápida 2: ¿Qué estructura decide si una respuesta es correcta?
Pregunta rápida 3: ¿Qué estructura evita escribir la misma pregunta 10 veces?
Pregunta rápida 4: ¿Qué estructura puede guardar muchas preguntas juntas?

👨‍💻 4. Construcción guiada · Predice antes de ejecutar

55–75 min

Step A · Estado inicial

when green flag clicked set [score] to [0] set [lives] to [3]
Predicción: ¿Qué valores deberían aparecer al iniciar el proyecto?

Step B · Entrada del usuario

ask [¿Cómo te llamas?] and wait say (join [Bienvenido/a ] (answer)) for [2] seconds
Predicción: ¿Qué valor cambia si otro estudiante usa el proyecto?

Step C · Decisión

if <(answer) = [4]> then change [score] by [1] say [¡Correcto!] else say [¡Intenta de nuevo!] end
Predicción: ¿Qué pasa si la respuesta es 4? ¿Qué pasa si la respuesta es 7?

Step D · Repetición

repeat [3] ask [Pregunta] and wait check the answer end
Predicción: ¿Cuántas rondas se ejecutarán? ¿Por qué un ciclo es mejor que copiar el mismo bloque tres veces?

📊 8. Rúbrica de proyecto

Criterio 4 · Excelente 3 · Bueno 2 · En desarrollo 1 · Inicio
Diseño del proyecto Propósito y arquitectura muy claros. Mayormente claros. Parcialmente definidos. Sin claridad.
Variables e ingreso Uso correcto y significativo. Funciona con pequeños errores. Uso parcial. Falta.
Condicionales La lógica funciona correctamente. Mayormente bien. Necesita depuración. Falta.
Ciclos Repetición eficiente y clara. El ciclo funciona. Funciona parcialmente. Falta.
Pruebas y depuración Prueba, identifica y corrige. Prueba y mejora. Pruebas limitadas. No prueba.
Creatividad y propósito Útil, claro y original. Claro y útil. Idea básica. Sin propósito claro.
