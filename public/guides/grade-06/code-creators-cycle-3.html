🎮 CODE CREATORS

Diseñamos una solución interactiva para nuestra comunidad We design an interactive solution for our community

Hoy trabajaremos como un equipo creador de tecnología. No necesitamos computadores para comenzar: observaremos nuestro entorno, elegiremos un problema, aprenderemos conceptos básicos de programación, diseñaremos una solución y construiremos un prototipo en papel que después podremos llevar a Scratch.
Today we will work as a technology creation team. We do not need computers to begin: we will observe our environment, choose a problem, learn basic programming concepts, design a solution, and build a paper prototype that we can later develop in Scratch.

🎯 Meta de la sesión 🎯 Lesson goal

🔎 ObservarObserve
Reconocer un problema real de la escuela o la comunidad.
Recognize a real problem in the school or community.
🧠 ComprenderUnderstand
Explicar algoritmo, variable, condicional, ciclo, lista y evento.
Explain algorithm, variable, conditional, loop, list, and event.
✏️ DiseñarDesign
Crear la idea de un juego, historia o herramienta interactiva.
Create the idea for a game, story, or interactive tool.
🤝 Construir juntosBuild together
Escuchar, proponer, organizar tareas y llegar a acuerdos.
Listen, propose, organize tasks, and reach agreements.

4. Programamos un robot humano 4. We program a human robot

Una persona será el robot. El robot solamente puede seguir instrucciones exactas. El equipo debe guiarlo desde un punto del salón hasta otro sin tocar obstáculos.
One person will be the robot. The robot can only follow exact instructions. The team must guide the robot from one point in the classroom to another without touching obstacles.

  4. Corrijan y vuelvan a probar.Correct it and test again.
