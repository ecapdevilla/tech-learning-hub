2 · Understand the MVC Connection

MODEL

Owns and manages the application data and its data rules.

Ask: What data does my app store?
VIEW

Shows information and interface elements to the user.

Ask: What does the user see and interact with?
CONTROLLER

Receives user actions, coordinates changes in the Model and requests View updates.

Ask: What happens after the user clicks or types?
USER→EVENT→CONTROLLER→MODEL→CONTROLLER→VIEW→UPDATED SCREEN

📓 MVC Connection Map

For your own project, write: MODEL — what data is stored? CONTROLLER — what functions change it? VIEW — what does the user see? EVENT — what action triggers the Controller?

3 · Core Functions You Must Complete

1

addTask()

Read user input, validate it, send the new item to the Model and update the View.

2

deleteTask()

Identify the selected item, remove it through the Model and render the new state.

3

completeTask()

Change the item's status through the Model and make the View show the change.

Adapt the names to your project. A store may use addProduct(), deleteProduct() and changeProductStatus(). An EcoTask project may use addTask(), completeTask() and deleteTask(). The MVC responsibility is what matters.

4 · Connect Controller and View With Events

// Example: the View detects an action
addButton.addEventListener("click", () => {
  controller.addTask(taskInput.value);
});

// Controller coordinates Model + View
addTask(text) {
  model.addTask(text);
  view.render(model.getTasks());
}

The exact code in your project may be different. Focus on the flow: an event happens → Controller receives it → Model changes → View renders the updated data.

5 · Engineering Test: Every Visible Control Must Work

A

Add

Can a user add a valid item and immediately see it?

B

Complete / Status

Can the user change its state and see a visible difference?

C

Delete

Can the user delete the correct item without breaking the application?

Engineering rule: A decorative button is not a completed feature. If the interface offers an action, test that the action actually works.

6 · Debug Like an Engineer

Do not rewrite everything when one feature fails.

1. Did the event fire?
2. Did Controller run?
3. Did Model change?
4. Did View render?

10 · Definition of Done

MVC

  • Model manages data
  • Controller coordinates actions
  • View renders the state

Functionality
