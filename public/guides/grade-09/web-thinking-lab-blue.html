Web Thinking Lab

HTML + CSS + JavaScript — Today the computer is your mind, your notebook is the screen, and your team is the browser.

Tech Learning Hub · 9th Blue
0–10 min

🎯 Learning Objective — Write it in your notebook

By the end of this class, I will understand how a web page is created from scratch, using HTML for structure, CSS for design, and JavaScript for interaction, so I can plan and explain how my own interactive web page should work.

After copying it, underline HTML, CSS and JavaScript. Then write one sentence about what you think each one controls.

10–25 min

🧠 Diagnostic: What do you already know?

Answer individually. Mistakes are useful because they show where our learning begins.

  1. What is a web page?
  2. What do you think HTML does?
  3. Where do colors and visual styles come from?
  4. What makes a button react when clicked?
  5. Draw a simple website with a title, paragraph and button.
Share one answer with a partner. If your answers are different, do not erase yours yet: compare the reasoning first.
25–45 min

📘 Essential vocabulary — Build your mini dictionary

Copy the term, its meaning, and add one example of your own.

HTML
Structure and content. Think: skeleton.
CSS
Appearance and design. Think: clothes and style.
JavaScript
Behavior and interaction. Think: actions.
Tag
HTML instruction such as <h1> or <button>.
Selector
Tells CSS which element to style.
Variable
A named place that stores a value.
Function
A reusable group of instructions.
Event
Something that happens: click, key press, etc.
Notebook task: Create three columns: HTML / CSS / JavaScript. Write two examples in each column.
45–65 min

🔎 Think like the browser

Read the code. Do not execute it. Predict the result first, then explain why.

Mission 1 — HTML
<h1>My School</h1> <p>Welcome to my website</p> <button>Explore</button>

Draw exactly what the browser should show.

Mission 2 — CSS
h1 { color: blue; } button { background: yellow; }

Which elements change? What does NOT change?

Mission 3 — JavaScript
let language = "es"; if (language === "es") { message = "Hola"; } else { message = "Hello"; }

What value will message contain? Explain the decision.

Mission 4 — Predict the event
button.addEventListener("click", function () { title.textContent = "Welcome!"; });

What must happen before the title changes?

65–75 min

🐞 Debugging on Paper

A programmer does not only write code. A programmer also finds and corrects problems.

Bug A
<h1>Hello</h2>

What looks inconsistent?

Bug B
if (language = "es") { message = "Hola"; }

What would you check in this condition?

Notebook rule: Do not write only the correction. Explain why you believe it is a problem.
75–105 min

🏆 Team Challenge: Build a Website Without a Computer

Teams of 4–5. Design on paper an interactive bilingual website. Every member must contribute.

Architect Designer Logic Developer Tester Presenter

Phase 1 · Idea — 5 min

Choose ONE useful page: school event, environmental campaign, sports club, study helper, cultural project, or your own idea. Define the user and purpose.

Phase 2 · HTML blueprint — 8 min

Draw the page and label at least: heading, paragraph, image area, two buttons and one information section. Beside each, write the HTML tag you would use.

Phase 3 · CSS design rules — 6 min

Choose background, text colors, button style and spacing. Write four CSS-style rules describing your choices.

Phase 4 · JavaScript behavior — 7 min

Create two interactions. Required: an English ↔ Spanish language button. Add another action: change message, show information, count points, change theme, etc. Write the logic in steps or pseudocode.

Phase 5 · Human Browser Test — 4 min

The Tester acts as the browser. Another member gives instructions. The Tester may do ONLY what the written instructions say. Find and correct at least one ambiguity or bug.

105–115 min

🎤 Lightning presentations

Each team has about 90 seconds: purpose → HTML → CSS → JavaScript → bug corrected.

EvidencePoints
Clear purpose and page sketch5
HTML structure makes sense5
CSS design decisions are explained5
Two logical interactions5
Team participation and explanation5
115–120 min

📝 Exit Ticket — Individual

  1. Complete: HTML is responsible for...
  2. Complete: CSS is responsible for...
  3. Complete: JavaScript is responsible for...
  4. What did your team change after testing its idea?
  5. Write one question you still have before building this page on a computer.
Final idea: A strong programmer does not begin by typing. A strong programmer first understands the problem, plans, predicts, tests and improves.
