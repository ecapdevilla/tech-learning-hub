🚀 My First Web Page

Complete learning guide · HTML + CSS + JavaScript

🎯 LEARNING OBJECTIVE

'By the end of this class, I will create my own web page from scratch using HTML for structure, CSS for design, and JavaScript for interaction, setting up my work environment in Visual Studio Code.'

📌 In simple words: You will create a complete web page with title, text, colors, working buttons, and language switching.

📚 TOPICS YOU WILL LEARN

HTML Structure

HTML (HyperText Markup Language) is the skeleton of your page. It defines headings, paragraphs, buttons, and all visible elements.

<!-- HTML Example -->
<h1>My Title</h1>
<p>This is a paragraph</p>
<button>Click me</button>

CSS Design

CSS (Cascading Style Sheets) is the clothing of your page. It controls colors, fonts, sizes, borders, and element positioning.

/* CSS Example */
h1 {
  color: blue;
  font-size: 30px;
  text-align: center;
}

JavaScript Interaction

JavaScript is the brain of your page. It makes buttons work, content change, and the page react to user actions.

// JavaScript Example
function greet() {
  alert("Hello!");
}

🎨 ACTIVITY 3: CSS STYLES (15 minutes)

📌 Your mission: Give color and design to your page

Add this code inside the <head> tag, after <title>.

<!-- COPY THIS INSIDE <head> -->

<style>

/* Styles for the whole page */
body {
  background-color: #f0f4f8;
  font-family: Arial, sans-serif;
  padding: 20px;
}

/* Styles for the title */
h1 {
  color: #16213e;
  text-align: center;
  font-size: 2.5rem;
}

/* Styles for paragraphs */
p {
  color: #2d3436;
  font-size: 1.1rem;
  line-height: 1.8;
}

/* Styles for the button */
button {
  background-color: #e94560;
  color: white;
  border: none;
  padding: 12px 30px;
  border-radius: 30px;
  cursor: pointer;
}

/* Changes when hovering */
button:hover {
  background-color: #c73652;
  transform: scale(1.05);
}

</style>

✏️ NOW CHANGE THE COLORS:

Background color: #f0f4f8 → change to lightblue, pink or #ff6b6b

Title color: #16213e → change to red, purple or #2ecc71

Button color: #e94560 → change to blue, green or #f39c12

🔘 ACTIVITY 5: INTERACTIVE BUTTONS (20 minutes)

📌 Your mission: Create buttons that work

Replace ALL the content inside <body> with this code.

🧪 TEST THE BUTTONS LIVE

💡 These buttons are an example. You will create your own.

<!-- CODE TO COPY INTO YOUR FILE -->

<body>
<div>

  <h1 id="tituloPrincipal">Hello, I am [YOUR NAME]!</h1>

  <p id="mensajeTexto">This text will change when you press a button.</p>

  <!-- BUTTONS -->
  <button onclick="cambiarMensaje('Hello from JavaScript!')">JS Greeting</button>

  <button onclick="cambiarMensaje('I am learning to code!')">Motivational</button>

  <button onclick="mostrarAlerta()">Show Alert</button>

  <button onclick="cambiarColorFondo()">Change Color</button>

</div>

<!-- JAVASCRIPT -->
<script>

// Function 1: Change the message
function cambiarMensaje(texto) {
  const elemento = document.getElementById('mensajeTexto');
  elemento.textContent = texto;
  console.log("📝 Message changed to: " + texto);
}

// Function 2: Show alert
function mostrarAlerta() {
  alert("🔔 You clicked the alert button!");
}

// Function 3: Change background color
function cambiarColorFondo() {
  const colores = ['#f0f4f8', '#ff6b6b', '#4ecdc4', '#ffe66d'];
  const aleatorio = colores[Math.floor(Math.random() * colores.length)];
  document.body.style.backgroundColor = aleatorio;
}

</script>
</body>

2. The button messages:
Change the texts between quotes with your own messages.

3. The alert message:

🌍 ACTIVITY 6: LANGUAGE BUTTON (STAR PROJECT) (20 minutes)

📌 Your mission: Create a translator for your page

Replace ALL the code inside <body> with this complete code. This is the star project of the class.

🌍 TEST THE LANGUAGE BUTTON LIVE

My Web Page

This is my first interactive web page.

💬 Message: Click a button to change the language.

💡 This is an example. You will create yours with your own texts.

<!-- COMPLETE LANGUAGE BUTTON CODE -->

<body>
<div>

  <!-- TITLES AND TEXTS -->
  <h1 id="tituloPrincipal">🌐 My Web Page</h1>

  <p id="descripcion1">This is my first interactive web page.</p>
  <p id="descripcion2">I am learning to program and this is amazing.</p>

  <!-- MESSAGE BOX -->
  <div id="cajaMensaje">
    💬 <strong>Message:</strong> Click a button to change the language.
  </div>

  <!-- LANGUAGE BUTTONS -->
  <button onclick="cambiarIdioma('es')">🇪🇸 Español</button>
  <button onclick="cambiarIdioma('en')">🇺🇸 English</button>
  <button onclick="cambiarIdioma('fr')">🇫🇷 Français</button>

</div>

<!-- JAVASCRIPT -->
<script>

function cambiarIdioma(idioma) {

  const titulo = document.getElementById('tituloPrincipal');
  const desc1 = document.getElementById('descripcion1');
  const desc2 = document.getElementById('descripcion2');
  const mensaje = document.getElementById('cajaMensaje');

  const textos = {
    es: {
      titulo: '🌐 Mi Página Web',
      desc1: 'Esta es mi primera página web interactiva.',
      desc2: 'Estoy aprendiendo a programar y esto es increíble.',
      mensaje: '💬 <strong>Mensaje:</strong> Haz clic en un botón para cambiar el idioma.'
    },
    en: {
      titulo: '🌐 My Web Page',
      desc1: 'This is my first interactive web page.',
      desc2: 'I am learning to program and this is amazing.',
      mensaje: '💬 <strong>Message:</strong> Click a button to change the language.'
    },
    fr: {
      titulo: '🌐 Ma Page Web',
      desc1: 'Ceci est ma première page web interactive.',
      desc2: 'J\'apprends à programmer et c\'est incroyable.',
      mensaje: '💬 <strong>Message:</strong> Cliquez sur un bouton pour changer la langue.'
    }
  };

  if (textos[idioma]) {
    titulo.textContent = textos[idioma].titulo;
    desc1.textContent = textos[idioma].desc1;
    desc2.textContent = textos[idioma].desc2;
    mensaje.innerHTML = textos[idioma].mensaje;
    console.log("🌍 Language changed to: " + idioma);
  }
}

</script>
</body>

✏️ CUSTOMIZE YOUR LANGUAGE BUTTON:

1. Change the Spanish texts: Write whatever you want in your language.

2. Change the English texts: Write the English translation.

3. Add a new language: Copy the structure of fr and add, for example, de (German).
