7TH GRADE · CYCLE 4 · 2-HOUR ENGINEERING LAB

Simulate Before You Build.

Mission: design and simulate an automated system using Wokwi or Tinkercad, then document how its input, decision logic and output work.

🎯 Learning objective

Use virtual simulation to test an automated system before physical construction, connecting sensor → processing → decision → actuator and documenting the engineering process clearly.

🧭 Engineering route

PROBLEM→INPUT / SENSOR→LOGIC→OUTPUT / ACTUATOR→SIMULATION→TEST→IMPROVE→DOCUMENT

🔎 Before building: investigate independently

Each team must identify what it needs. If you already know a component, explain it. If you do not, investigate it using reliable sources. Do not copy a long definition; answer these engineering questions:

  • What does the sensor detect?
  • What value or signal does it produce?
  • What decision must the system make?
  • What actuator responds?
  • What should happen in normal and alert conditions?

1 · Guided reference: Security System

PIR SENSOR ↓ movement? MICROCONTROLLER ↓ IF movement detected LED / BUZZER ↓ ALERT

The guided example is a reference for understanding automation. Your team should later design its own automated system.

2 · Your own system

Choose a real need and create a simulation. Examples of contexts:

  • Water use / tank level
  • Security / access
  • Smart lighting
  • Temperature alert
  • Plant / soil monitoring
  • Waste / environmental monitoring

3 · Minimum simulation requirements

  • One clearly defined problem
  • At least one input/sensor
  • At least one output/actuator
  • One IF/THEN decision rule
  • A working Wokwi or Tinkercad simulation
  • At least three test scenarios
  • A diagram or written technical explanation
  • Peer feedback and one documented improvement

🏁 Evidence to submit

  • Project name and problem
  • Screenshot/link of the simulation
  • System diagram
  • Sensor and actuator explanation in your own words
  • Decision rule / logic
  • Three test results
  • One improvement after peer review
  • Short reflection: How did simulation help improve the design?

📱 No computer available?

You can still complete the research, system blueprint, component selection, IF/THEN logic, circuit sketch and test plan from a phone + notebook. When a computer is available, you should be ready to implement immediately instead of starting the planning again.
