En este ciclo, los estudiantes explorarán cómo crear una interfaz web dinámica con autenticación, gráficos y almacenamiento local, desarrollando una propuesta clara y aplicable al diseño de sistemas digitales.

Opening / Motivation

Lasallian greeting: We begin with a respectful and calm greeting. We remember that technology must serve people and the community.

Question: “What should a good dashboard include?”
Examples to observe
Dynamic dashboards with charts, login forms, filters, status cards and tables.
Key idea
A web dashboard helps people interpret information and make decisions faster.
Materials
Notebook, pencil, colored pencils, projector if available.
15–35 min

Development / Representation

Objective: Students will understand how a dynamic website can organize information, protect access with authentication, present data with charts, and store user preferences locally.
1. Dynamic web interface

A dashboard is a web page that shows information clearly and updates when data changes.

Think of it as a control panel.

2. Authentication

Authentication means identifying who the user is before allowing access.

Examples: login form, username, password, session.

3. Charts

Charts help show patterns, comparisons and progress visually.

Examples: bars, lines, pie charts.

4. Local database

localStorage stores data in the browser so users can keep settings or small information without a server.

Notebook task: Write a definition in your own words for: dashboard, authentication, chart, localStorage, and user session.
35–70 min

Core Concepts · What Students Need to Know

Web interface

HTML provides structure, CSS provides design, JavaScript makes it dynamic.

HTML → structure CSS → design JavaScript → interaction
Authentication

The user enters credentials; the system validates them before showing the dashboard.

username = "admin" password = "1234" IF user enters correct data THEN open dashboard
Charts

Chart.js is a JavaScript library that makes graphs easier to create in a web page.

new Chart(ctx, { type: 'bar', data: { labels: ['Jan', 'Feb'], datasets: [...] } });
Local database

localStorage can save preferences or records locally in the browser.

localStorage.setItem('theme', 'dark'); const theme = localStorage.getItem('theme');
Notebook challenge: Explain in 5 lines how the browser can remember the user’s preferred theme or last value selected.
70–90 min

Guided Project Planning

Students must plan the dashboard before coding. They should write the structure in their notebook.

Section What it does Example
Login Allows access to the dashboard Username and password
Home panel Shows summary values Total sales, users, alerts
Chart area Visualizes the information Bar chart or line chart
Table Shows detailed data List of records
Settings Lets users change simulation configuration Theme, limits, colors
Design prompt: Create a dashboard for a school’s energy system. Include a login page, energy charts, report table and a settings panel.
90–105 min

Prompt Engineering Intro

Students need to learn how to communicate clearly with AI tools and coding assistants. Prompt engineering helps us give instructions that are precise, structured and useful.

Simple prompt example:
Create a dashboard for a school with a login form, three cards with statistics, and a line chart showing energy consumption for the week.
Improved prompt example:
Act as a web developer. Generate a clean dashboard interface in HTML, CSS and JavaScript with: a login form, a navigation bar, three summary cards, a bar chart showing monthly data, and a table with student names and scores. Use a modern blue color palette and responsive design.
Good prompt includes
  • Role
  • Goal
  • Context
  • Output format
Prompt checklist
  • What should it do?
  • Which technologies to use?
  • What output should appear?
  • What design style should it have?
Prompt task: Write two prompts: one for a login page and one for a dashboard with charts. Then explain which prompt is better and why.
105–120 min

Closure / Action and Expression

Gallery walk / peer sharing: Students compare their dashboard ideas and discuss what elements are useful for decision-making.

Reflection questions:
  1. How can a dashboard help in decision-making?
  2. Why is authentication important in a web system?
  3. How do charts make data easier to understand?
  4. What information can be stored locally and why is it useful?
  5. How can prompt engineering help you create a better solution faster?
Final notebook ticket: Write 5 lines answering: What did I learn today? What was easiest? What was hardest? What would I improve at home?

Homework / Home Practice

1. Draw a mockup of the login page.
2. Draw a dashboard with at least 3 cards and 1 chart.
3. Write the data structure that your dashboard will use.
4. Define 3 variables for the project.
5. Add one prompt for an AI assistant to generate the code.
6. Explain what localStorage would save for your project.
