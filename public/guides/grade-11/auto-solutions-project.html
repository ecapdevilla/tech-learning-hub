AUTO-SOLUTIONS

Ingeniería de Sistemas Robóticos con Interfaz Web

💻 Tecnología ➕ Matemáticas 🔬 Ciencias Naturales

🎯 OBJETIVO DEL PROYECTO

Diseñar, simular, documentar y presentar un sistema robótico funcional que integre sensores, actuadores, comunicación inalámbrica (WiFi) y una interfaz web para monitoreo y control, utilizando Wokwi (simulador), JavaScript, HTML y CSS, que resuelva un problema real en la escuela o comunidad, aplicando conceptos de Tecnología, Matemáticas y Ciencias Naturales, y promoviendo los Objetivos de Desarrollo Sostenible (ODS).

📋 METODOLOGÍA

Los estudiantes trabajarán como equipos de ingeniería robótica cuya misión es desarrollar una solución automatizada que integre hardware (simulado), software y ética, para abordar una necesidad real de la comunidad.

El proyecto seguirá la metodología de Aprendizaje Basado en Proyectos (ABP), el enfoque STEM y el Proceso de Diseño en Ingeniería.

🔍 PASO 1: IDENTIFICAR EL PROBLEMA

Los estudiantes:

  • Conocerán los Objetivos de Desarrollo Sostenible (ODS) - Enfoque en ODS 3 (Salud y Bienestar), ODS 6 (Agua Limpia y Saneamiento), ODS 9 (Industria, Innovación e Infraestructura), ODS 11 (Ciudades y Comunidades Sostenibles), ODS 13 (Acción por el Clima).
  • Identificarán problemas en su escuela o comunidad que puedan resolverse con un sistema automatizado (riego inteligente, seguridad, monitoreo ambiental).
  • Explorarán cómo la integración de robótica y web puede mejorar la calidad de vida.
  • Analizarán las implicaciones éticas y ambientales de la automatización.
❓ Pregunta Orientadora:
¿Cómo podemos integrar un sistema robótico con una interfaz web para crear una solución automatizada que aborde un problema real de nuestra comunidad, considerando las implicaciones éticas, ambientales y sociales, y alineándonos con los Objetivos de Desarrollo Sostenible?

👥 PASO 2: FORMAR LOS EQUIPOS DE INGENIERÍA

El docente organizará equipos de trabajo colaborativo.

  • Cada salón se dividirá en 6 equipos de ingeniería.
  • Cada equipo estará conformado por 4 a 5 estudiantes.
  • Cada miembro asumirá un rol y responsabilidad específica.

Roles Sugeridos:

⚙️ Ingeniero de Hardware Responsable de sensores, actuadores y simulación en Wokwi
💻 Ingeniero de Software Responsable de la programación y lógica del sistema
🌐 Desarrollador Web Responsable de la interfaz web (HTML/CSS/JS)
📝 Documentador Responsable de la documentación (APA) y bitácora
🎤 Líder de Innovación Lidera presentaciones y conexión con ODS

📚 PASO 3: INVESTIGAR Y PLANIFICAR

Los estudiantes investigarán:

  • Sensores: ultrasónico, temperatura (DHT11), humedad del suelo, PIR, luz.
  • Actuadores: servomotores, LEDs, zumbadores, motores DC.
  • Microcontroladores: ESP32 (simulado en Wokwi).
  • Comunicación inalámbrica: WiFi.
  • Interfaz web: HTML, CSS, JavaScript, Chart.js.
  • Almacenamiento local: localStorage o JSON.
  • Ética y sostenibilidad en automatización.
  • Conceptos de ciencias naturales relacionados (ciclo del agua, energía, residuos).

Cada equipo creará:

  • Un nombre para el proyecto.
  • Diagrama de arquitectura del sistema (robot + web).
  • Diseño de la interfaz web (wireframes).
  • Selección de sensores y actuadores.
  • Plan de desarrollo.

Opciones de Proyecto Disponibles:

💧 Riego Inteligente Automatización con sensor de humedad y control web
🔐 Sistema de Seguridad Alarma con sensor PIR y notificaciones web
♻️ Clasificación de Residuos Sistema con sensores y reporte web
🌡️ Monitoreo Ambiental Sensores de temperatura, humedad y calidad del aire
🌱 Huerta Escolar Monitoreo de cultivos con datos en tiempo real

✏️ PASO 4: DISEÑAR EL PROTOTIPO

Los equipos diseñarán:

  • Arquitectura del sistema (robot + web).
  • Circuito electrónico en Wokwi.
  • Interfaz web (wireframes).
  • Flujo de comunicación (robot → web).
  • Estructura de datos (JSON/localStorage).

Los estudiantes producirán diagramas, wireframes y documentos de planificación.

🛠️ PASO 5: CONSTRUIR Y PROGRAMAR

Los estudiantes:

  • Configurarán el simulador Wokwi.
  • Conectarán sensores y actuadores.
  • Programarán el microcontrolador (ESP32).
  • Crearán la interfaz web (HTML/CSS/JS).
  • Implementarán comunicación WiFi.
  • Conectarán el sistema completo (robot + web).

Componentes del Sistema:

📡 Sensores Ultrasónico, DHT11, humedad, PIR
⚡ Actuadores Servomotor, LED, zumbador
🌐 WiFi Comunicación con la interfaz web
📊 Interfaz Web Dashboard, gráficos, control

Características Posibles:

  • ✅ Monitoreo de sensores en tiempo real (datos en web).
  • ✅ Control de actuadores desde la web (ON/OFF).
  • ✅ Gráficos dinámicos (Chart.js).
  • ✅ Almacenamiento de datos (localStorage).
  • ✅ Autenticación básica (login).
  • ✅ Alertas y notificaciones.
  • ✅ Conexión con ODS y sostenibilidad.

🧪 PASO 6: PROBAR Y RECOLECTAR DATOS

Los estudiantes:

  • Probarán el sistema completo (simulación).
  • Medirán tiempos de respuesta y precisión de sensores.
  • Registrarán datos en tablas y gráficos.
  • Compararán diferentes configuraciones.
  • Recibirán retroalimentación de usuarios.

Integración con Matemáticas y Ciencias Naturales:

  • Matemáticas: Lógica de programación, estructuras de datos, gráficos, estadística básica, mediciones, ángulos, distancias.
  • Ciencias Naturales: Ciclo del agua, energía, residuos, biodiversidad, ecosistemas, cambio climático (según el proyecto elegido).

Los estudiantes determinarán cuál sistema es el más eficiente y sostenible.

🔧 PASO 7: MEJORAR EL DISEÑO

Los equipos:

  • Analizarán los resultados de las pruebas.
  • Corregirán errores en programación y simulación.
  • Optimizarán el código.
  • Mejorarán la interfaz web.
  • Agregarán nuevas funcionalidades.
  • Documentarán las mejoras con comentarios.

Los estudiantes documentarán todas las mejoras en su bitácora de ingeniería.

🎤 PASO 8: PREPARAR LA PRESENTACIÓN DEL PRODUCTO

Cada equipo preparará:

  • Demostración del sistema robótico (simulación).
  • Demostración de la interfaz web.
  • Explicación de la arquitectura (robot + web).
  • Explicación del código y componentes.
  • Conexión con ODS y sostenibilidad.
  • Reflexión ética sobre automatización.

Los equipos explicarán cómo su sistema contribuye al bienestar de la comunidad escolar y al cuidado del planeta.

🏆 PASO 9: FERIA STEM DE INNOVACIÓN

Cada equipo participará en la Feria de Innovación Auto-Solutions.

Los estudiantes:

  • Exhibirán su sistema robótico simulado.
  • Demostrarán la interfaz web.
  • Explicarán la integración robot-web.
  • Explicarán cómo ayuda a la comunidad y al medio ambiente.
  • Recibirán retroalimentación de docentes y compañeros.

📌 RESUMEN DEL PROYECTO

Al final del proyecto, cada equipo habrá desarrollado un sistema robótico funcional con interfaz web que combina:

Componente Aplicación
Tecnología Robótica (sensores, actuadores, ESP32), Web (HTML/CSS/JS)
Matemáticas Lógica, estructuras de datos, gráficos, estadística, mediciones
