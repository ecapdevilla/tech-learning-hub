🤖 Sistema Inteligente de Clasificación de Residuos

Proyecto realizado por:
Valentina y Salma

Este sistema representa una solución tecnológica para una empresa dedicada a la clasificación automática de residuos. El programa utiliza estructuras de programación como condicionales y bucles para tomar decisiones y repetir procesos automáticamente.

Quiz tipo ICFES: Programación aplicada a residuos

1. Una empresa utiliza un sistema que identifica si un residuo es plástico, vidrio u orgánico mediante una condición. ¿Qué estructura de programación utiliza?

2. Un robot clasificador revisa 500 residuos uno por uno. ¿Qué estructura permite repetir esta acción automáticamente?

3. Un programa analiza un residuo y dice: "Si es reciclable, enviarlo al área verde". ¿Qué concepto representa?

4. En un sistema automático de reciclaje se necesita repetir una tarea 10 veces exactamente. ¿Cuál estructura es más adecuada?

6. Si un programa usa un ciclo while y nunca cambia la condición, ¿qué puede suceder?

7. Una empresa crea un programa que revisa residuos hasta encontrar uno peligroso. ¿Qué estructura sería útil para repetir la búsqueda?
