SISTEMA AUTOMATIZADO DE CLASIFICACIÓN INTELIGENTE DE RESIDUOS

Contribución al ODS 12 - Producción y Consumo Responsables

Automatización mediante Condicionales y Bucles

Descripción del Proyecto

Este sistema automatiza la clasificación de residuos para promover el reciclaje, reducir la contaminación y facilitar la correcta disposición de materiales. El programa utiliza condicionales para determinar el tipo de residuo y un bucle para procesar múltiples registros de manera automática, simulando un sistema utilizado en empresas o centros de reciclaje.
