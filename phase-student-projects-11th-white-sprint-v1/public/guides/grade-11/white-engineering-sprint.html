Definition of “finished” for this Cycle

  • ☐ One coherent problem connected to an ODS.

  • ☐ Wokwi simulation demonstrates sensor → decision → actuator.
  • ☐ Web interface displays useful system data and/or controls.
  • ☐ WiFi/data flow is implemented or technically demonstrated as required by the project.
  • ☐ At least 3 tests have expected result, actual result and evidence.
  • ☐ Technical documentation explains components, logic, ethics/sustainability and limitations.
  • ☐ Final presentation demonstrates evidence rather than unsupported claims.
