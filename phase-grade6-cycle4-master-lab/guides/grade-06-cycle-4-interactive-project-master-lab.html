🧠 2. Master Class · The Five Building Blocks

15–40 min
📦

Variable

A named place that stores information that can change.

Un espacio con nombre que guarda información que puede cambiar.

score = 0 lives = 3 name = "Ana"
⌨️

User Input

Information provided by the user.

Información que entrega el usuario.

ask "What is your name?" answer → name
🔀

Conditional

A decision: IF something is true, do an action.

Una decisión: SI algo es verdadero, realiza una acción.

IF score >= 10 YOU WIN
🔁

Loop

Repeats actions efficiently.

Repite acciones de forma eficiente.

REPEAT 5 TIMES ask question
📚

Array / List ⭐ Advanced Challenge

A structure that stores several related values, such as questions, answers, names or story options.

Una estructura que guarda varios valores relacionados, como preguntas, respuestas, nombres u opciones de historia.

questions = ["2+2?", "5+3?", "10-4?"] answers = ["4", "8", "6"]
Quick Check 1: Which structure should store the player's score?
Quick Check 2: Which structure decides whether an answer is correct?
Quick Check 3: Which structure avoids writing the same question code 10 times?
Quick Check 4: Which structure can store many questions together?

👨‍💻 4. Guided Build · Predict Before Running

55–75 min

Step A · Start state

when green flag clicked set [score] to [0] set [lives] to [3]
🔮 Predict: What values should appear when the project starts?

Step B · User input

ask [What is your name?] and wait say (join [Welcome ] (answer)) for [2] seconds
🔮 Predict: Which value changes when another student uses the project?

Step C · Decision

if <(answer) = [4]> then change [score] by [1] say [Correct!] else say [Try again!] end
🔮 Predict: What happens when the answer is 4? What happens when it is 7?

Step D · Repeat

repeat [3] ask [Question] and wait check the answer end
🔮 Predict: How many rounds will occur? Why is a loop better than copying the same blocks three times?
