ODS 12 - Producción y Consumo Responsables

Sistema Automatizado para la Gestión Inteligente del Reciclaje

Este sistema contribuye al cumplimiento del Objetivo de Desarrollo Sostenible N.° 12, permitiendo registrar y analizar la cantidad de residuos reciclables generados durante varios días. Utiliza condicionales para evaluar el desempeño ambiental y un bucle para procesar múltiples registros de manera eficiente.
