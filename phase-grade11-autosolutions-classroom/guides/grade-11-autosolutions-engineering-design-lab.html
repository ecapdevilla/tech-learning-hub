Engineering Design Lab — From a Real Problem to a Smart System

Today you will not build the robot yet. You will think and work like an engineering team: identify a problem, design the logic, select sensors and actuators, plan the data flow and sketch the web interface.

🎯 Learning Objective — Write it in your notebook

Design the initial proposal for a smart automated system that responds to a real school or community problem by integrating sensors, actuators, WiFi communication and a web interface, while considering sustainability and the Sustainable Development Goals (SDGs).
✍️ NOTEBOOK / CUADERNO: Copy the objective. Underline: problem, sensors, actuators, WiFi, web interface and SDGs.
12–27 min

🧠 Activate Your Engineering Thinking

Answer individually before discussing with anyone.

  1. What problem at school or in your community could technology help solve?
  2. What information would a machine need to detect?
  3. What action should the system perform automatically?
  4. What information should a user see on a web page?
  5. What could go wrong if the system makes a bad decision?
Now improve one answer after comparing ideas with a partner. Write what you changed and why.
27–42 min

📘 Essential Engineering Vocabulary

Sensor
Detects or measures a condition in the environment.
Actuator
Performs a physical action.
ESP32
Microcontroller that processes information.
WiFi
Wireless communication used to exchange data.
Web Interface
Screen where users monitor information.
Automation
A system performs actions according to programmed rules.
Data
Values collected by the system.
SDG / ODS
A Sustainable Development Goal.
Create a two-column mini-dictionary: TERM | MEANING IN YOUR OWN WORDS.
