STUDENT PROJECTS · DOWNLOADABLE HTML V1

Purpose:
Allow students to download their own published HTML project and continue improving it.

This upgrade applies automatically to every current project found under:
public/student-projects/**/index.html

It also improves the gallery ProjectCard with:
- EXPLORE PROJECT
- DOWNLOAD HTML

And every published project receives a floating:
- Download HTML

Privacy:
Downloads are the public sanitized versions, so surnames removed for privacy remain removed.

Important:
Most current projects are single-file HTML projects and can be continued directly.
If a future project depends on local CSS, JavaScript, images or other files, that project should receive a ZIP download instead of only HTML.

Install:
.\phase-student-projects-downloads-v1\install-student-project-downloads.ps1
