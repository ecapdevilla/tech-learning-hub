3 · Integrate All JavaScript Structures

Variables

Store meaningful state: score, level, total, selected option, timer or user input.

Conditionals

Create decisions and rules with if/else or equivalent logic.

Loops

Process or display repeated data instead of duplicating code.

Functions

Organize reusable actions with clear responsibilities.

Arrays

Manage collections: questions, waste items, records, options, scenarios or products.

Events + DOM

Respond to user actions and update the screen with the new application state.

Engineering rule: Do not add code only to satisfy the checklist. Every structure must have a real purpose in your application.

4 · Turn the Prototype Into an Interactive Experience

1

Input

The user clicks, chooses, types, drags or starts an action.

2

Logic

JavaScript processes the action using your structures and rules.

3

Feedback

The interface visibly responds with a result, state, score, message, chart or next step.

Your project can keep its identity. A recycling game can add levels and scoring; a footprint simulator can add scenarios and classifications; a data application can add filters, calculations or interactive results. You do not all need the same feature.

5 · Example of Meaningful Integration

// Array: collection of scenarios
const scenarios = [
  { name: "Low impact", limit: 20 },
  { name: "Medium impact", limit: 50 },
  { name: "High impact", limit: Infinity }
];

// Function + loop + conditional
function classifyImpact(total) {
  for (const scenario of scenarios) {
    if (total <= scenario.limit) return scenario.name;
  }
}

// Event + DOM feedback
calculateButton.addEventListener("click", () => {
  const total = calculateTotal();
  result.textContent = classifyImpact(total);
});

Do not copy this blindly. Identify the equivalent need in your own project and adapt the logic.

6 · Test and Debug Like an Engineer

Find the failing layer before changing code.

1. Input / Event
2. Data / State
3. Logic / Function
4. DOM / Feedback

Minimum test cases

Test a normal case, a limit/edge case and an invalid or unexpected input. Record what you expected and what actually happened.
