🧠 2. Master Class · From Chart to Dashboard

15–35 min
📊

Static Chart

Shows a fixed view. To analyze another part, you often modify the source or chart manually.

Muestra una vista fija. Para analizar otra parte, normalmente debes modificar manualmente la fuente o el gráfico.

🎛️

Dynamic Chart

Responds to filters, slicers or changes in connected data.

Responde a filtros, segmentadores o cambios en los datos conectados.

📈

Line Chart

Best for trends over time.

Ideal para tendencias a través del tiempo.

📶

Bar Chart

Best for comparing categories.

Ideal para comparar categorías.

Professional question before choosing a chart: “What question am I trying to answer?”

📋 Pivot Table

Summarizes and groups data.

📊 Chart

Transforms values into patterns we can see.

🎛️ Slicer

Lets the user filter interactively.

🎨 Conditional Formatting

Highlights important values automatically.

🛠️ 3. Guided Build · From Cycle 3 Pivot Table to Dashboard

35–60 min
Mission: Use the pivot table created in Cycle 3 and transform it into a dashboard.
  1. Select the Pivot Table from Cycle 3.
  2. Insert a Bar Chart to compare categories.
  3. Insert a Line Chart to observe a trend.
  4. Add at least one Slicer.
  5. Apply Conditional Formatting to highlight important values.
  6. Add a clear dashboard title and labels.
🔮 Predict: What should change when you select one value in the slicer?
